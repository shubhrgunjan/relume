one line

Give your agent taste it can measure.

curl -fsSL https://relume.shubhrgunjan.me/install.sh | sh

Installs what it needs (Node, git, ffmpeg, a headless browser), finds your agents — Claude Code, Codex, Gemini, Antigravity, Cursor, Windsurf, VS Code, OpenCode, Goose — and asks which to set up. --agents claude,codex · --yes · --uninstall

If the one-liner fails, set it up by hand
  1. Requirements: Node 20+, git and ffmpeg (brew install node git ffmpeg · sudo apt install nodejs git ffmpeg).
  2. Get relume:
    git clone https://github.com/shubhrgunjan/relume ~/.relume
cd ~/.relume && npm install
  3. A browser to measure with: npx playwright install chromium. If Playwright has none for your system (e.g. macOS 13), use your Chrome instead: add RELUME_BROWSER_CHANNEL=chrome to the server's environment below.
  4. Check the server starts (it answers with its tools; Ctrl-C to stop): 
    npm --prefix ~/.relume run -s stdio
  5. Register it with your agent (the command is npm, the arguments --prefix ~/.relume run -s stdio):

    Claude Code

    claude mcp add --scope user -e RELUME_DATA=$HOME/.relume/data relume -- npm --prefix $HOME/.relume run -s stdio

    Codex · ~/.codex/config.toml

    [mcp_servers.relume]
command = "npm"
args = ["--prefix", "/Users/you/.relume", "run", "-s", "stdio"]
tool_timeout_sec = 900.0

    Cursor ~/.cursor/mcp.json · Gemini CLI ~/.gemini/settings.json · Antigravity ~/.gemini/antigravity/mcp_config.json · Windsurf ~/.codeium/windsurf/mcp_config.json

    { "mcpServers": { "relume": {
  "command": "npm",
  "args": ["--prefix", "/Users/you/.relume", "run", "-s", "stdio"],
  "env": { "RELUME_DATA": "/Users/you/.relume/data" } } } }
  6. Restart your agent and ask it: “extract https://linear.app with relume and build me a page in its language”.

Only want a language, not the tool? Every catalogue entry above has its skill as a download: unpack it into .claude/skills/ (or your agent's skills folder) and build.
