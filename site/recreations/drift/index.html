Why real physics?

01

Momentum
you can feel

Velocity is sampled from the pointer and handed to an integrator, not a timeline.

02

Springs,
not easings

Interrupt any motion mid-flight and it carries on from where your finger left it.

03

Native
scroll stays

Sticky, scroll-snap fallbacks and screen readers keep working. Drift only moves what you ask.

One import. Real weight.

Point Drift at any row of elements. It measures them, listens to pointer, wheel and keys, and runs a single spring per track on requestAnimationFrame.

npm i @drift-ui/core
import { Drift } from '@drift-ui/core'

// any element with children becomes a track
const drift = new Drift('.gallery', {
  mass: 1,
  stiffness: 170,
  damping: 26,
  friction: 0.92,
  snap: 'nearest',
  loop: true,
})

drift.on('settle', ({ index }) => console.log(index))
